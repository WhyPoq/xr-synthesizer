## Proposal

The user will learn how to generate sounds using synthesizers

How will users learn:

1) Users will be introduced to each component of the synthesizer step by step:
    - Oscillator (sin, triangle, saw, square)
    - Filter
    - Envelope (can control both filter and amplitude)

2) Users will get a challenge on each step:
    - Identify the shape of the wave they hear
    - Try to tweak the filter to closely match the reference sound
    - Create fade in effect using envelope

3) After the introduction, users will be able to create 3 instruments (f.e., bass, flute, strings) and they will be used to play a song

For technologies, XR tools will be used to allow for all the interactions with the synthesizer (nobs, switches, buttons)
